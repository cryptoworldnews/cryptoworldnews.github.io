How to Set Up MetaMask and Get Your First Address

How to set up a MetaMask wallet step by step: install the official extension, create and back up your wallet, then copy your first receiving address.

Merkle Street NewsroomNov 21, 2026 · 09:26 UTC#22147d4 min read

This walkthrough takes you from an open desktop browser to a backed-up MetaMask wallet with a copyable receiving address. The 12-word Secret Recovery Phrase restores the wallet; the password only unlocks it on the device where you set it.

What to have ready before installing MetaMask

Start with a desktop browser and a pen and paper. MetaMask is available as an extension for Chrome, Firefox, Brave and Edge, and as an iOS or Android app. These steps cover the desktop extension.

Before setup, you have a browser open and no wallet. After setup, Account 1 will show an address beginning with 0x. Your browser and device stay the same; what changes is that MetaMask has created a wallet and displayed its public address.

Install MetaMask and create a backed-up wallet

  1. Open metamask.io and add the extension. Follow the site’s link to the relevant browser store listing and install MetaMask from there. The extension appears in your browser. Using the official site matters because fake extensions can copy MetaMask’s name.
  2. Choose “Create a new wallet.” In the extension, select the option to create a wallet and follow the setup prompts. MetaMask begins setting up a new wallet on your device.
  3. Set a strong password. Enter a password you can use to unlock MetaMask on this device. The extension accepts it and continues to the recovery phrase. This password encrypts the wallet on this device; MetaMask cannot reset it for you.
  4. Reveal and write down the Secret Recovery Phrase. MetaMask displays 12 words. Write them on paper in the exact order shown, then keep the paper somewhere private and secure. Do not put the phrase in a screenshot, cloud note or chat. Anyone with the phrase can restore the wallet, so treat it like the key to the wallet.
  5. Re-enter the requested words to confirm. Select or type the words MetaMask asks for, in the correct order. When the confirmation succeeds, the wallet setup is complete. The phrase follows the BIP-39 standard; it is the backup that can restore the wallet if you lose access to this device or forget its password.
  6. Pin the extension and copy your address. Use your browser’s extension menu to pin MetaMask, then open it and select the address shown under Account 1 to copy it. A copied address starts with 0x; that is your receiving address.

The password and phrase have different jobs. The password unlocks the encrypted wallet on this device. The Secret Recovery Phrase restores the wallet on another device, so keep the paper backup safe and never share the words with anyone claiming to help.

One address can receive assets on Ethereum and Shibarium

Your MetaMask address works across Ethereum Virtual Machine (EVM) networks, including Ethereum and Shibarium. The address stays the same when you switch networks, but each network keeps its own record of the tokens sent there.

Say someone sends tokens to your address on a network you have not added to MetaMask. The tokens still arrive on that network; they may not appear in your wallet view until you add the network. Adding it lets MetaMask display and interact with that network’s activity. Before sending or searching for tokens, check that you are viewing the network they were sent on.

This is useful when connecting to a decentralized exchange such as shiba swap, which lets users interact with exchange features through a connected wallet. On the site, choose “Connect Wallet,” select MetaMask, and approve the connection in the extension. Connecting lets the site interact with your wallet address; it does not move funds. Review any separate transaction in MetaMask before approving it.

Related questions

Can I use the same MetaMask wallet on phone and computer?

Yes. Install the official MetaMask app on your phone and restore the existing wallet with its Secret Recovery Phrase. The same phrase restores access to the same wallet and address. Enter it only in the official app; do not send it to another person or enter it on a website that asks for it.

What happens if I forget my MetaMask password?

The password cannot be reset by MetaMask. Restore the wallet using the Secret Recovery Phrase, then set a new password on the device. If you lose both the device access and the phrase, the password alone cannot restore the wallet.

  • Keep the written Secret Recovery Phrase in a private, secure place.
  • Copy the Account 1 address when you need to receive assets.
  • Check the selected network before looking for tokens or approving a transaction.
