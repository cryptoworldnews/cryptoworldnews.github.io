What a Connected Wallet Does While a Swap App Quotes

A connected wallet supplies the account and network while a swap app checks routes and prices; the quote is read-only, and a later trade still needs approval.

Merkle Street NewsroomOct 3, 2026 · 16:36 UTC#05285c2 min read

A wallet can stay connected while a swap app refreshes quotes because the connection identifies an account and network, while quoting is usually a read-only lookup. The app uses that context to request possible routes for the selected tokens and amount. The wallet does not sign a trade just by staying connected.

What does a wallet connection provide during a quote?

Connecting gives the app access to the wallet’s public address and the selected network. The app can use those details to show balances or prepare a quote for that account and chain. The private key stays in the wallet; the connection does not hand it to the app.

The quote request can then check available pools or other sources for a route between the two tokens. For a fuller walkthrough of exchanging Ethereum tokens with a connected wallet, see fermi swap. A quote is like asking for a current price: it gives information, but does not commit the buyer to a purchase.

How does a swap quote change while the wallet stays connected?

The app sends the chosen token pair and amount to its quote source, which checks routes and returns an estimated output. The app may refresh that estimate as pool prices or available liquidity change. A quote can also become stale if the market moves before the transaction is submitted.

When the user chooses a route, the app prepares a transaction for the connected network. The wallet then shows the transaction details and asks for approval. Only after the user signs can the transaction be sent; the quote itself does not move tokens.

What should you check before using a refreshed quote?

Check that the wallet and app are on the intended network, and confirm the input token, amount, and expected output before signing. A refreshed quote can differ from the one first displayed because prices and liquidity can move. The wallet’s transaction confirmation is the point to review what the app is asking it to authorize.

  • Confirm the token pair and amount in the app.
  • Check the selected network in both the app and wallet.
  • Review the current output estimate and any displayed price impact or fees.
  • Read the wallet’s transaction request before signing.

Keeping a wallet connected can make repeated quotes easier because the app retains the account and network context. It does not lock in a price or approve a swap. Treat each quote as a temporary estimate, then review the transaction in the wallet before signing.
