How to Return Mantle Assets for an Exchange Deposit

To deposit Mantle-held crypto at an exchange, first check whether it accepts the Mantle network; otherwise withdraw through the bridge to a supported chain.

Merkle Street NewsroomSep 30, 2026#9ac98e3 min read

To deposit assets held on Mantle at an exchange, first check which networks that exchange accepts for the exact token; if Mantle is not listed, bridge the asset to a network the exchange supports. The exchange credits a deposit only after the asset arrives on the network selected on its deposit page. A matching token name is not enough: the sending network, receiving network and token must all line up.

Can I deposit directly from Mantle to an exchange?

You can deposit directly if the exchange lists Mantle as a supported network for that particular asset. Open the exchange’s deposit screen, select the asset, and inspect the available network options. If Mantle appears, copy the deposit address and choose Mantle as the network in your wallet’s send flow. Check any memo or tag requirement the exchange displays; some assets require one in addition to an address.

If Mantle is absent, the exchange may accept the same token only on Ethereum or another chain. The token on Mantle cannot be sent to that other network’s deposit address as if the chains were interchangeable. You need to move it across chains first. This is the role of the bridge: its contracts process a withdrawal from Mantle and release the corresponding asset on the destination chain. A fuller explanation of the Mantle Bridge withdrawal route for exchange deposits covers how that transfer fits together.

How do I bridge an asset back to a deposit network?

Start by confirming the exchange’s supported network and deposit details. Then use a bridge route that supports both Mantle and that destination network, and that handles the specific token you hold. The steps are straightforward, but each confirmation controls a different part of the transfer:

  • On the exchange, select the asset and destination network. Copy the deposit address and check whether a memo or tag is required.
  • In your wallet, open the bridge and set Mantle as the source and the exchange’s network as the destination. Select the same asset and enter the amount.
  • Review the estimated amount after fees, then approve the token if the bridge requests permission to use it. Confirm the withdrawal transaction in your wallet.
  • Wait for the bridge to complete the transfer. Once the asset is on the destination network, send it to the exchange address using that same network.

A bridge withdrawal may involve more than one on-chain transaction. The first starts the withdrawal on Mantle; another step may be needed to prove or finalise it on the destination chain. Follow the bridge’s status and prompts, and keep enough MNT in the wallet to pay Mantle transaction fees. The exchange deposit itself may also need confirmations before the balance appears.

What should I check before sending the deposit?

Compare the token and network shown by the exchange with the asset and destination shown by the bridge. Also check the minimum deposit, fees and any deposit instructions on the exchange, since these can differ by asset and can change. If the bridge delivers a different token representation than the exchange lists, do not send it until you have confirmed that the exchange accepts that version.

For most readers, the simplest route is the one with the fewest handoffs: deposit directly from Mantle when the exchange explicitly supports that network; otherwise bridge to the exchange’s stated network, then make a separate deposit. A small test transfer can help confirm the address and route before sending a larger amount, though it may incur fees twice.
