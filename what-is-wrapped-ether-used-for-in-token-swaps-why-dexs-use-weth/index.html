What is wrapped ether used for in token swaps: Why DEXs use WETH

What is wrapped ether used for in token swaps? WETH lets swap contracts handle ETH as an ERC-20; wrapping and unwrapping take gas, with no exchange fee.

Merkle Street NewsroomNov 24, 2026 · 03:47 UTC#d120203 min read

WETH lets token swap contracts handle ETH as an ERC-20 token, so pools and trading systems can move it using the same functions they use for other tokens.

  • Use WETH when a pool or swap order requires an ERC-20 token.
  • Wrapping or unwrapping requires ETH and network gas, with no exchange fee.

Why swaps use WETH

DEX pools pair WETH rather than native ETH because their contracts move ERC-20 tokens. ERC-20, defined in EIP-20, provides functions such as approve and transfer that contracts use to authorize and move tokens; native ETH has no such token functions.

Think of WETH as an adapter: it represents ETH in a form that a token pool can process. The WETH contract holds deposited ETH and mints the same amount of WETH. When you redeem WETH, the contract burns it and returns the corresponding ETH.

That conversion is one to one: 1 WETH is redeemable for 1 ETH through the WETH contract. Wrapping and unwrapping cost network gas, but no exchange fee. Gas is the network cost of processing the transactions, so the amount you spend on it can vary; the conversion itself does not charge a fee.

That distinction matters when using cowswap, where orders are signed for ERC-20 tokens. A native ETH sell is wrapped before settlement so the order can be handled in the token format the trading system uses.

What happens when you swap ETH for USDC?

For an ETH-to-USDC swap, the router wraps the ETH into WETH, swaps that WETH through a pool, and sends USDC to your wallet.

Take this illustrative case: before the swap, your wallet holds native ETH and no WETH. You choose ETH as the asset to sell and USDC as the asset to receive. The router deposits the ETH into the WETH contract, which mints an equal amount of WETH. The router then sends that WETH into the swap and receives USDC in return.

After settlement, your wallet has less ETH and more USDC, while the pool has received WETH and sent out USDC. The conversion changes which assets you hold; the WETH step lets the pool process the ETH value through ERC-20 functions. The example describes the route, not a particular rate or fee: those depend on the trade and network conditions.

A cowswap order follows the same token requirement. The trader signs an order using ERC-20 tokens, and native ETH is wrapped before settlement when it is the asset being sold. This lets the order interact with token trading while the trader starts with ETH.

When do you need to unwrap WETH?

Unwrap WETH when you need native ETH in your wallet, including for gas. A completed swap can leave you with WETH as a separate token entry, rather than native ETH, even though each WETH is redeemable for one ETH.

Before, your wallet might show WETH from a swap and less native ETH than you expected. After you withdraw that WETH through the WETH contract, it is burned and the equivalent ETH returns to your wallet. The value represented stays one to one; what changes is the token form, and the withdrawal costs network gas.

For your next trade, check whether the pool or order expects WETH, then wrap ETH before the trade or unwrap WETH afterward if you need native ETH for gas.
