How do you buy an ERC-20 token with hardware signing?

To buy an ERC-20 token with a hardware wallet, connect its Ethereum account, review the swap, authorize spending, sign the order, and verify receipt.

Merkle Street NewsroomNov 19, 2026 · 03:25 UTC#14807f4 min read

To buy an ERC-20 token with a hardware wallet, connect its Ethereum account through MetaMask, review the cowswap trade, authorize any required allowance, and sign the order. The device signs; cowswap arranges execution, so the purchased tokens go to the selected address.

Run the purchase from the connected account

Start with a configured hardware wallet and a compatible connector. The device must be able to sign for the Ethereum account you intend to use.

  1. Connect the hardware account in MetaMask. Choose its hardware-wallet option, connect the device, and compare the displayed account with the address shown on the device. Keep the seed phrase offline; you should not need to enter it into MetaMask or a website. MetaMask’s hardware-wallet instructions cover its connection and signing flow.

  2. Fund the account with the token you will sell and ETH for ordinary approval gas. Before trading, verify the purchase token’s contract address on Ethereum against a trusted source. A familiar token name or ticker alone does not confirm that you have the right contract.

  3. Open cowswap and set the sell token, purchase token, amount, and recipient. Review the spender and allowance, the estimated output, and the minimum output you will accept. The recipient should be the hardware account you checked. On cowswap, signed trade orders enter solver-run batch auctions. The gasless swap cowswap topic adds background on gasless swap mechanics; cowswap still needs your signed order before solvers can execute it.

  4. Authorize spending if the trade requires an allowance, then sign the swap order on the device. Read the on-device request and confirm its account and details before approving. Approval lets the spender use the specified sell token within the allowance; it is separate from signing the trade order. The cowswap swap walkthrough describes approval, signing, and completion.

  5. Wait for the order status to show completion, then check the purchased token balance at the selected recipient address. The task is complete when the order is completed and the tokens have arrived there.

Once cowswap accepts the signed order, your hardware device can disconnect while solvers execute it. The device’s role is to authorize the account’s action; it does not need to stay connected for the accepted order to settle. This is useful for a returning user: signing ends the device interaction, while execution continues through the order process.

  • Configured hardware wallet — the device connects and displays the account address you intend to use.

  • Compatible connector — MetaMask offers a hardware-account connection for your device.

  • Sell tokens and approval gas — the Ethereum account holds the sell amount and enough ETH for an ordinary approval transaction if needed.

Related questions

Can you unplug a hardware wallet after signing?

Yes. After the order is accepted, solvers can execute it without the device connected. Reconnect only if a later action asks for another signature.

Can you buy crypto with a bank card and a hardware wallet?

A separate fiat on-ramp can fund the hardware address. Once the tokens arrive, use that account for the Ethereum purchase and keep the recipient address consistent.

More hardware-wallet questions

How do I revoke leftover allowance?

Use a trusted allowance-management tool to find the token and spender, then submit a revocation or reduction transaction from the same account. Review the contract and transaction on your device; changing an allowance requires an on-chain transaction and gas.

How do I cancel an unfilled order?

Use the order’s cancellation option in the trading interface and sign the cancellation if prompted. Check the order status afterward, since a cancellation request must take effect before the order can no longer be filled.

Can hardware wallets sign TWAP orders?

That depends on whether the wallet connector supports the order flow and signing request. Review the order details on the device and confirm the interface accepts your account before relying on a TWAP order.

What happens if my hardware wallet breaks?

The wallet device can be replaced using the seed phrase in a compatible wallet, which restores access to the same account. Keep the seed phrase offline and never share it with a support agent or enter it into an untrusted site.
